\begin{abstract}

ESP32s equipped with capacitive moisture sensors have recently been suggested for IoT plant watering systems. However, measuring moisture in soil is complex and requires careful calibration in order to characterise the response curve mapping soil moisture content to sensor measurements, which end consumers are unlikely to undertake. Even accurately measuring soil moisture content requires effort, with variability across soils and environmental conditions, and consumer-grade probes tending to offer coarse measurements only. As a result, in a consumer growing context, soil moisture is commonly ascertained by intuition. If IoT sensor systems are to be practically useful, calibration must be easy. Here, we demonstrate a novel approach for automated calibration of sensor systems requiring minimal end-user inputs, and offering measures of uncertainty. This work has the potential to assist with low-cost automated monitoring of growing conditions.

\end{abstract}

\subsection{Watering event detection}

Raw sensor data is continuously streamed into the database system. From there, event detection is performed on recent time intervals. Event detection is performed in several steps: initial triggers based on outlier time series deltas; of the trigger events, hysteresis detection by testing for stability of change in a window; subsetting to events with a sign consistent with watering; consensus amongst sensors for a single microcontroller; manual exclusion of known non-watering events such as sensor removal or repositioning; evaluation. Firstly, denoting measurement at $t_i$ of sensor $s$ as $X_{i,s}$, which are assumed to be continuously generated by the software system previously described, the distribution of $\Delta X_{i,s}$ in manually-defined event-free time intervals can be gathered, and with a threshold $p$, extreme values are taken as candidates if $|\Delta X_{i,s}|$ is greater than a threshold. In this case, using the median absolute deviation \hl{TODO: cite}:

\[
 \frac{|\Delta X_{i,s}|}{c \cdot median_i(\Delta X_{i-w:i})} > p
\]

Secondly, since watering events are assumed to cause stable changes in sensor measurements, persistent change was defined by considering change in sensor values without long term trends (e.g. drying) removed using an exponentially weighted moving average \hl{TODO: cite}:

\[
Y_i = X_i - EMWA_\lambda(X)_i
\] 

\[
\min\limits_{i < j < i+k}{|Y_{j,s} - Y_{i,s}|} > q
\]

Given an event candidate at $t_{i+1}$ and window size $k$; for the sensors chosen, $X$ is decreasing in water content, so only events with negative change are assumed to be watering. In addition, only events for which all sensors attached to a given microcontroller agree on an event were taken. This resulted in a classification parameterized by two thresholds, two window sizes, and a median absolute deviation scale factor: $(p, q, k, w, c, \lambda)$. \\

Manual recording of watering times, false negatives, and false positives via the system API are used characterise performance of the rule.
