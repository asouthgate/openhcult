\begin{abstract}

ESP32s equipped with capacitive moisture sensors have recently been suggested for IoT plant watering systems. However, measuring moisture in soil is complex and requires careful calibration in order to characterise the response curve mapping soil moisture content to sensor measurements, which end consumers are unlikely to undertake. Even accurately measuring soil moisture content requires effort, with variability across soils and environmental conditions, and consumer-grade probes tending to offer coarse measurements only. As a result, in a consumer growing context, soil moisture is commonly ascertained by intuition. If IoT sensor systems are to be practically useful, calibration must be easy. Here, we demonstrate a novel approach for automated calibration of sensor systems requiring minimal end-user inputs, and offering measures of uncertainty. This work has the potential to assist with low-cost automated monitoring of growing conditions.

\end{abstract}

\subsection{Watering event detection}

Raw sensor data is continuously streamed into the database system. From there, event detection is performed on recent time intervals. Event detection is performed in several steps: initial triggers based on outlier time series deltas; of the trigger events, hysteresis detection by testing for stability of change in a window; subsetting to events with a sign consistent with watering; consensus amongst sensors for a single microcontroller; manual exclusion of known non-watering events such as sensor removal or repositioning; evaluation. Firstly, denoting measurement at $t_i$ of sensor $s$ as $X_{i,s}$, which are assumed to be continuously generated by the software system previously described, the distribution of $\Delta X_{i,s}$ in manually-defined event-free time intervals can be gathered, and with a threshold $p$, extreme values are taken as candidates if $|\Delta X_{i,s}|$ is greater than a threshold. In this case, using the median absolute deviation \hl{TODO: cite}:

\[
 \frac{|\Delta X_{i,s}|}{c \cdot median_i(\Delta X_{i-w:i})} > p
\]

Secondly, since watering events are assumed to cause stable changes in sensor measurements, persistent change was defined by considering change in sensor values without long term trends (e.g. drying) removed using an exponentially weighted moving average \hl{TODO: cite}:

\[
Y_i = X_i - EMWA_\lambda(X)_i
\] 

\[
\min\limits_{i < j < i+k}{|Y_{j,s} - Y_{i,s}|} > q
\]

Given an event candidate at $t_{i+1}$ and window size $k$; for the sensors chosen, $X$ is decreasing in water content, so only events with negative change are assumed to be watering. In addition, only events for which all sensors attached to a given microcontroller agree on an event were taken. This resulted in a classification parameterized by two thresholds, two window sizes, and a median absolute deviation scale factor: $(p, q, k, w, c, \lambda)$. \\

Manual recording of watering times, false negatives, and false positives via the system API are used characterise performance of the rule.

\subsection{Automated response curve calibration}

In general, soil water content is difficult to measure, requiring completely comparison of completely dry soil mass to a given wet soil mass \hl{TODO: cite}. Consumer-grade soil moisture probes generally report coarse, normalized measurements. Here, we define dimensionless moisture content as $Z$, the ratio of water volume to dry soil volume (such as in a pot). We assume that $Z$ itself is not directly measurable, although at a given watering, $\Delta Z$ is measurable if a known amount of water is added. We fix this and refer to it as $W$ \hl{TODO: this is a simplifying assumption; you can add 100 ml of water at peak saturation and $\Delta Z$ is zero, or lose water to runoff} \\

For convenience, the system relies on automatically detected watering events previously described. For a given event at time $t_i$, we extract associated $X_{i,s}$. This leads to sampled pairs $(\Delta Z_{i,s}, X_{i,s})$. We asssume the relationship:

\[
X_{i,s} = h(Z_{i,s}) + \epsilon_i
\]

Where $\epsilon_i$ is Gaussian noise. In this equation, both the response function $h(\cdot)$ and the water content $Z$ are unknown. Given a known starting point, such as $Z_0 = 0$, and a sequence of waterings, $Z_{i,s}$ could be reconstructed as $Z_0 + \sum_{i} \Delta Z_{i,s}$ and $h(\cdot)$ determined by regression. However, we assume in general that the range $[Z_0, Z_{max}]$ of completely dry to completely saturated is not tolerable for any plant, so such watering sequences will not be obtainable outside from specific calibrations which do not generalise well. We assume that our system will produce at best sequences of waterings within a range, and at best single samples. \hl{TODO: drying in between waterings}. Then we have:

\[
X_{i, s}^{(k)} = h(c + \sum_{j<i}\Delta Z_{j,s}^{(k)}) + \epsilon_i = h(c + S_{i, s}^{(k)}) + \epsilon_i
\]

Where $(k)$ is an index for a given sample trajectory samples from the collection of sensors. In this case, $h$ could be determined by regression except for the unknown constants $c$, which also must be determined. These unknown values $c$ determine horizontal shifts or coordinate change in the curve $X(Z)$. \\

Although we do not have ideal watering sequences for calibration, it is more reasonable to assume it is possible to obtain some noisy sampled pairs $(Z, X)$, such as at in fully dry or fully wet conditions, which can be used to constrain the estimation problem. Then, we want to solve:

\[
\min\limits_{h, \vec{c}}{\sum_{s=1}^S \sum_{i=1}^{n_s} \Big[ X_{s,i} - h(c_s + S_{s,i})\Big]^2 + \sum_{j=1}^m w_{j} \Big[X_j - h(Z_j)]^2 \Big]}
\]

where the RHS term is the anchor samples, with weights $w_j$ (taken by default to be a single $w$). Optionally, with the additional regularisation:

\[
\lambda \sum_s (c_s - \overline{c})^2
\]

\hl{Not sure that the $\overline{c}$ makes sense, can't it be zero?}. \\

It is expected that, in order to characterise $h$ properly, the samples must sufficiently overlap. For regions of the response curve where there is no data, there is no information to estimate $h$. \\

In order to solve this optimisation problem, an iterative approach was used where 1) given a candidate $h$, $c$ can be identified by one-dimensional optimisation and 2) given $c$, $h$ can be estimated with isotonic regression. \\

In order to characterise the performance of this algorithm under the given assumptions, simulation was performed.
